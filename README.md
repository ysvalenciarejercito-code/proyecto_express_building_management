Este repositorio contiene las entregas semanales del proyecto del bootcamp **bc-reactnative**, dictado por el profesor Erick Granados (SENA).

Reemplaza al bootcamp bc-flutter para este trimestre, por problemas técnicos de instalación de Flutter en los equipos del SENA. ## Estructura de entregas

Cada semana del bootcamp se entrega en una rama independiente dentro de este mismo repositorio, siguiendo el formato:

```
week-01
week-02
week-03
...
```

El número de semana siempre se escribe con dos dígitos. Este es el único repositorio usado durante todo el trimestre para las entregas de bc-reactnative.

## Proceso de entrega semanal

1. Adaptar el proyecto de esa semana al dominio de Administraciòn de edificios (recursos, campos, datos de ejemplo).
2. Subir el código a la rama `week-<NN>` correspondiente en este repositorio.
3. Enviar el correo de entrega a `profeerickgranados@gmail.com` con el siguiente formato:

   ```
   Asunto: bc-reactnative semana <NN> ficha <ficha>
   Cuerpo: https://github.com/<usuario>/<este-repo>
   ```

4. Realizar la entrega antes del plazo: **2 días calendario antes de la próxima clase, hasta las 11:59pm**.
